# Foil Design

This folder contains the design files for the foil used with the fly holder assembly jig.

## Files

- `FlyMetal_AL_M_S Drawing v2.pdf`: manufacturing drawing.
- `FlyMetal_AL_M_S.f3d`: Fusion 360 design file.
- `FlyMetal_AL_M_S.step`: STEP file for CAD review or manufacturing workflows.

## Manufacturing Notes

- Tolerances: +/- 0.002 in.
- Material: 0.001 in stainless steel 316, annealed.
